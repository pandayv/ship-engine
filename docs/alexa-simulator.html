SHIP · Alexa+ simulation

Ask what's going on. See it on a screen.

A web simulation of the Alexa+ interaction, calling SHIP's real, deployed MCP server (Relay) over Streamable HTTP — not a mock. Voice states a count and a destination; the findings themselves only ever render on a screen.

Built per the Alexa+ track's own submission rules, which explicitly permit "a simulated Alexa+ experience in a web app" as an alternative to a live device connection. Every response below comes from a real tools/call request to Relay's production endpoint — open your browser's network tab if you'd like to see it.
