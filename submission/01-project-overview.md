# Project overview page

## Project name (60 characters)

SHIP

## Elevator pitch (200 characters)

SHIP reviews every pull request for AI compliance risk, blocks the merge when it finds a problem, and lets you decide by voice while the detail shows on the screen nearest you.

(176 characters. Two shorter options:)

- An AI compliance gatekeeper for pull requests. It blocks risky merges, cites the exact regulation, and lets a person decide by voice, with the detail on the nearest screen. (172)
- AI code that skips a compliance check ships a legal decision nobody signed off on. SHIP blocks the merge, cites the rule, and asks a person to allow or block it by voice or screen. (180)
