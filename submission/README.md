# Submission pack

Paste-ready text for the Devpost submission, in the order Devpost shows it.

| File | Devpost page |
|---|---|
| `01-project-overview.md` | Project overview: name, pitch, tags, links, gallery, video |
| `02-project-story.md` | Project details: "About the project" |
| `03-additional-info.md` | Additional info: every field, the AWS and open-source write-ups, testing, feedback |
| `gallery/` | Image gallery files (3:2) |

The long-form documents live in the repository root and are linked from the form: `README.md`, `PRODUCT_FEEDBACK.md`, `FRICTION_LOG.md`, `SETUP.md`.

## Only you can do

- Fill the fields marked **YOU** in `03-additional-info.md` (submitter details, checkboxes, and your own words for the last three questions).
- Upload the video and paste its link.
- Upload the gallery images.
- Check every link once in a private window.
- Keep the deployment running until judging ends on November 20.
